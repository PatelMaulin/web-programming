## Final project: The Cricket Club

The integrated final project is in **[final-project/](final-project/)**. It includes the cricket website, account registration, login sessions, a profile with saved preferences, dark mode, player filtering, and a rules quiz.

Requires Node.js 24 or newer. From the repository root:

```sh
cd final-project
npm ci
npm test
npm start
```

Open http://localhost:3000. See [the project guide](final-project/README.md) for features, setup, and the demonstration checklist.

This is preparation for the final project. Nothing has been submitted to iCollege. Earlier assignments remain in the repository root; use the final-project directory for the integrated application.
