CRICKET WEBSITE - ABOUT PAGE ASSIGNMENT

OPEN THE PAGE
Extract this ZIP first. Open about.html in a browser to review the new page,
or open index.html to begin at the home page. Keep styles.css next to the
HTML files and keep the images folder in the same location.

WHAT IS INCLUDED
- about.html: Three paragraphs about the site's purpose and motivation,
  plus a link to LED Energy Plus, the creator's business website.
- styles.css: An external stylesheet with a commented color palette and
  font choices. The palette colors are used for backgrounds and text.
- index.html, history.html, players.html: The existing pages, updated with
  an About navigation link. Their original content has been preserved.
- images/: The original local cricket images.

The optional personal photograph and logo have not been added.
Read the first-person paragraphs and edit them to match your own voice.

ADD THE FILES TO YOUR EXISTING GITHUB REPOSITORY
1. Extract the ZIP and open the cricket_about_assignment folder.
2. Put its contents in the same repository folder as your existing website.
   Review any differences before replacing newer versions in your repository.
   The required new/changed code files are about.html, styles.css, index.html,
   history.html, and players.html. The image files are unchanged.
3. In GitHub, open that folder and choose Add file > Upload files.
4. Upload the extracted files, not the ZIP. Use this commit message:
   Add About page and external stylesheet color palette
5. Finish the upload by committing the changes, or proposing them on a new
   branch when your repository requires that workflow.
6. Open the resulting commit and copy its browser address.
7. Submit the COMMIT URL to your class assignment. Do not submit the ZIP,
   just the repository homepage, or just the live website URL.

A GitHub commit URL has this format (example placeholders, not a real link):
https://github.com/YOUR-USERNAME/YOUR-REPOSITORY/commit/COMMIT-ID

No remote Git commit has been created by this download. Your actual commit
URL exists after you commit the files in your own repository. Make sure your
instructor has access to the repository.

OPTIONAL TERMINAL METHOD
Run these from your existing cloned repository after copying and reviewing
the files. This assumes the branch is already tracking its remote branch:

git add about.html styles.css index.html history.html players.html
git diff --cached
git commit -m "Add About page and external stylesheet color palette"
git push
